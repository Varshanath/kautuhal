# Kautuhal Lab

The coming-soon page for [kautuhal.whiteboxacademy.in](https://kautuhal.whiteboxacademy.in), a
program by [Whitebox Academy](https://whiteboxacademy.in). It's a plain static site hosted on
GitHub Pages, so pushing to `main` publishes it.

The waitlist doesn't send anywhere until `WAITLIST_ENDPOINT` is set in `script.js`.
